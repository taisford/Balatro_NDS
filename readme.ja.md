**BalatroをNintendo DS向けに移植することを目指す、非公式の自作ソフト（homebrew）プロジェクトです。**

Balatro DSは、Nintendo DS向けhomebrew開発の可能性を学び、実験し、探求するために作られた、個人による非営利の開発プロジェクトです。

PC版 *Balatro* のゲーム体験をNintendo DSのハードウェア上で可能な限り忠実に再現することを目標としています。そのために、ゲームシステム、インターフェース、演出を本体の制約に合わせて調整しながら、1:1に近いゲーム体験を目指しています。

本プロジェクトは独立して開発されており、Balatroの原開発者や発売元との提携・承認・関係を示すものではありません。

## プロジェクトの目標

- PC版の主要なゲームプレイの仕組みを再現する。
- ポーカーの役判定とスコア計算を可能な限り忠実に実装する。
- オリジナル版の進行システム、ラウンド、経済システムを再現する。
- Nintendo DS向けにインターフェースと操作方法を調整する。
- 実機のNintendo DSで高い再現度のBalatro体験を実現できるか検証する。
- 低レベル開発やゲームの挙動のリバースエンジニアリングを通じて学び、改善する。

## 現在の状況

**開発進行中 — 初期段階のプレイ可能なプロトタイプ。**

現在は、テキスト中心の基本的なプロトタイプです。以下の機能を実装しています。

- 標準的な52枚のトランプの生成とシャッフル。
- 8枚の初期手札。
- Nintendo DSの操作によるカードの移動と選択。
- 基本的なポーカーの役判定。
- チップ、倍率、最終スコアの初期計算。
- カードをプレイしたり捨てたりする基本操作。手札をすべてなくすことも可能です。

ゲームの基本的な進行ループはまだ完成していません。現在は、ラウンド制のゲーム体験を実装する前段階として、基礎部分の開発を進めています。

### 開発中 / 今後の実装予定

- ジョーカーシステムの拡張と、より多彩なオリジナル効果の追加。
- ランごとに3枚のジョーカーが並ぶ、ランダムなショップオファーの実装。
- ラウンド進行、ブラインド、スコア目標の完全な実装。
- プレイ可能なハンド数と捨て札の回数制限。
- カードの補充とデッキ管理の改善。
- 追加のゲームメカニクスとカード強化要素。
- グラフィックやアニメーションの改善、およびNintendo DSの2画面に最適化した、より原作に忠実なインターフェース。
- Nintendo DSハードウェア向けのさらなる最適化。

まだ開発初期段階のため、機能や互換性は開発の進行に応じて変更される可能性があります。

## 開発について

本プロジェクトはC言語で開発され、Nintendo DS向けhomebrew開発環境の[BlocksDS](https://blocksds.skylyrac.net/)を使用しています。

PC版のオリジナルゲームは、ゲームの仕組みを理解し再現するための挙動の参考として使用しています。PC版の実行ファイルをNintendo DS上で直接動かすことを目的としたプロジェクトではありません。
